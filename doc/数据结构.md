# 数据结构设计（folio-model）

公共词汇表：诸 crate 共用的**类型**。只有数据，零行为、零依赖。

## 三条规矩（新类型进来先过三问）

1. **只有数据**——struct / enum + serde 与纯算术；行为留在消费它的 crate（扩展 trait）。
2. **两个以上 crate 要用才进来**——只用一个的留在原 crate。
3. **换 crate 不换形状**——serde 逐字节稳定，库里的载荷不迁移。

## 类型一览

### format — 格式与章表

```rust
enum Format            // 21 个格式
struct DocMeta         // 书目：书名 / 作者 / 语言 / 出版 / ISBN / 系列…（两族同一份）
struct Chapter         // 标题 + 位置 + 规范化字数 + 图片引用清单
enum ChapterLocator    // Entry(容器条目名) / Section(单文件第几章) / Inline(正文随文档)
```

### content — 内容两族

```rust
struct FlowDoc         // 可重排：章表 + CSS 清单 + 目录 + 封面 + 全书图片 + 字符集
struct FixedDoc        // 定版式：页是既定画布
enum ContentKind       // 两族分流的那一格
```

### position / anchor — 位置与锚点

```rust
struct Locator         // 章内字符偏移，不认页码
struct TextAnchor      // 坐标 + 找回坐标的文本指纹（重定位算法在 folio-core）
```

### types — 书库记录的行形状

```rust
BookRow / ShelfItem / BookMeta       // 书目与书架行
Annotation / Bookmark / Collection   // 批注 / 书签 / 集合
ReadingSession / DailyReading / ReadingRank   // 阅读统计
```

### 其他

- **novel**——txt 分章规则的读者差量（出厂表与引擎在 folio-format）。
- **reading**——阅读偏好的档位词汇（如图往哪块尺寸折）。
- **char_class**——词 / 空白 / 换行分类，划词吸附共用。

## 优化（现有实现里已经做了的）

- **边界有测试看着**——清单里出现解析 / 排版 / 数据库 / 网络 / 界面即红
  （boundary test 逐行扫 Cargo.toml）。
- **换 crate 不换形状**——类型搬进 model 后旧路径 re-export，调用方一行不改。
- **行为挂扩展 trait**——`Chapter::inline`、`copy_extension` 这类与解析绑定的
  方法住 folio-format，model 保持只有数据。
