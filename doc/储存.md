# 储存 API 设计（SQLite 书库）

`Store` 是一个类型、一把锁；前端读书架 / 进度 / 批注 / 统计，导入写它。
实现按主题拆文件，API 按主题列。**机制住 folio-store crate**（2026-11-12 阶段四拆分，
原 folio-core::store 与书库资产的落盘约定原样搬去；`folio_core::store::*` 旧路径经
模块别名沿用，rusqlite 随行）。错误自持（`folio_store::Error`：SQL、载荷 JSON、
带标签的本地 I/O、集合名校验——原 core 伞枚举的 `Sql` / `EmptyCollectionName` 两格
删除，伞枚举经 `From` 收编整条链）。卡点「book_settings → config」由阶段二先解掉：
store 只碰 `BookSettings` 的数据与列编解码（都在 folio-model），咬配置的 effective/record
行为经 `BookSettingsExt` 留在 core，store 的生产代码一行不沾。

## 使用顺序（一屏看完）

```rust
let store = Store::open_default()?;            // 或 open_at(path) / in_memory()（测试）
let items = store.shelf("")?;                  // 书架清单
store.set_position(book_id, mode, &locator)?;  // 离开书时存位置
let pos = store.position(book_id)?;            // 回来时取
```

## API 一览

### 开库

```rust
Store::open_default() -> Result<Store>   // 默认路径
Store::open_at(path: &Path)              // 指定路径
Store::in_memory()                       // 测试用
store.backup_to(path)                    // 整库备份
store.vacuum() -> Result<u64>            // 回收空间，回可回收字节数
```

### 书目与书架（books）

```rust
store.add_book(path, &meta) -> Result<i64>          // 入库，回 id
store.shelf(query) -> Vec<ShelfItem>                // 书架（可搜索）
store.shelf_grouped(query, by) -> Vec<ShelfGroup>   // 按作者 / 分组聚合
store.book(id) / book_meta(id) / book_cover(id)     // 单本、书目、封面字节
store.book_by_hash(hex) -> Option<BookRow>          // 按内容身份找（导入去重用）
store.set_book_meta(id, title, authors)             // 改书名 / 作者
store.remove_book(id)                               // 删书（连副本与缓存）
store.touch_opened(id)                              // 记「打开过」
```

### 进度与已读

```rust
store.set_position(book_id, mode, &locator)          // 存阅读位置
store.position(book_id) -> Option<(mode, Locator)>   // 取
store.mark_chapter_read(book_id, idx) / read_chapters(book_id)
```

### 批注 / 书签 / 集合

```rust
store.add_annotation(...) / annotations(book_id) / update_annotation / delete_annotation
store.add_bookmark(book_id, &anchor) / bookmarks(book_id) / delete_bookmark
store.create_collection(name) / add_to_collection(coll, book) / books_in_collection(coll)
```

- 批注与书签挂在 `TextAnchor`（文本指纹）上，文档变了能找回位置。
- 删除都配一条 restore（撤销用）。

### 阅读统计

```rust
Snapshot::load(&store, range, anchor, tz_offset_secs)   // 统计屏一份全拿
```

分桶、补零、连签都在这层算好，界面只摆；**时区是参数**。

### 笔记聚合（notes）

跨书把批注 + 书签折成 `BookGroup` 清单（分组、排序、封面字节齐），笔记屏直接摆。

## 优化（现有实现里已经做了的）

- **一次调用只上锁一次**——公开方法拿守卫调 `*_in(&conn)` 助手，助手不再碰锁，
  `Mutex` 不可重入，方法套方法就是自锁。
- **拆文件不拆实体**——主题各一份文件，`Store` 仍是一个类型一把锁。
- **迁移只增不改**——schema 是日志式清单，老库一路升上来不重写。
- **封面字节去重**——同 hash 的封面盘上只留一份。
- **口令不同步**——读者口令按本机存，刻意不进同步。
