# 定版式接进公共翻页装配（Curl 与双页）

读者 2026-11-03 定的口径：把定版式那条臂并进公共装配，翻页档统一成文档那一套 ——
**包括让 PDF / 漫画也支持仿真折页与双页**。基线 = commit `7016e293`（`body 渲染层拆成模块，
三种摆法统一成 Paper 装配`，未推送）。

行号会漂，认符号名不认行号。

## 现状账（已核对）

- 翻页档 **5 / 6**：定版式可用 `Slide` / `SlideUp` / `Cover` / `Scroll` / `None`，只筛掉
  `Curl`。判据 `chrome::fixed_turn_applies`（`model/chrome.rs:329`），三处收口同一个数：
  设置弹层那一格 `components/reading_sheet.rs:584`、起翻页 `model/paging.rs:286`、
  渲染帧 `view/body/fixed.rs:530`（`chrome::fixed_turn_style`）。
- 摆法 **2 / 3**：定版式默认恒为分页，读者手动选的 `Spread` 被降级（`view/body.rs:401`）。
- 捕获链对定版式是关着的：`view/body.rs:548` `let capture_front = capture_needed && !self.is_fixed();`。
- 定版式的翻页位移**不吃手指**：`fixed.rs:530` 起算时 `Pose { grip: None, revert: None }`，
  且用的是降级后的档位，所以走不到 release 时钟那一支。

筛掉 `Curl` 的理由写在代码里：仿真折页要一张**排版页**的捕获纹理，而定版式那一页是位图，
当初没有那条捕获链。所以这条链的顺序是「先补捕获，再放档」。

## 已经公共化的部分（在基线里）

`view/body/turn_view.rs` 是翻页那一层的唯一入口，两条臂共走：

- `paint_shades` / `request_front_capture` / `request_back_capture` / `request_incoming_capture`
  / `paint_curl_mesh` / `mount_capture_layers` —— 折面投影、三张纹理的请求、网格、三份副本入树。
- `build_curl_mesh`（`turn_view.rs:434`）—— 圆柱几何 + 顶点缓存 + uniform + 途中读数日志。
- `plan_sheets`（`:578`）—— 按档答出 `curl_area`、自由边在哪一侧、带手与弹回时钟的 `Pose`。
- `plan_flat`（`:671`）—— 平摊三档「出场 / 进场页改用整页纹理」的判定；「哪些页不许进捕获层」
  以两个闭包交给调用方（可重排问 `span_doc` + 整页画 + `is_current`）。

## 链（顺序即依赖）

**① 定版式产出捕获副本**
`paint_fixed_paper`（`fixed.rs:708`）现在把页格往公共 `overlays` 推（`:759`、`:799`）。改成
一份交给 `PaperCapture { element, under, over, bands }`：位图与放大重画块进 `over`，字层的
痕迹与选中**仍留实时层**（定版式的字在栅格图里，痕迹必须压在页图之上 —— 与可重排相反）。

**② 打开闸**
`body.rs:548` 的 `!self.is_fixed()` 换成一条有效性判据：这一页的每一格都已经在图集里
（`tile.request` 解出了像素）才算「可烘」，否则这一帧不请求。三问在
`capture.rs:46 front_valid` / `:56 incoming_valid` / `:78 capture_wanted`。
**这一步单独做是净退步**：纹理烘出来没人采，等于给 PDF 白加一趟捕获 pass。①②③必须连着做。

**③ 接平摊与卷曲**
`plan_flat` 的 `eligible` 对定版式放开；`plan_sheets` 取代 `fixed.rs:530` 那段手写 `Pose`
（**这是行为变更**：定版式从此跟手，并走 release 时钟）。定版式的 `page_area` 就是整张纸
（`content == paper`），所以 `curl_area` 天然是整页。网格采 ① 烘出来的那张。

**④ 放开档与摆法**
删 `chrome::fixed_turn_applies` 对 `Curl` 的筛档 + `body.rs:401` 的 `Spread → Paged` 降级，
设置弹层那一格同步放开。**已定（读者 2026-11-03）**：定版式双页 = **相邻两页各占半张**
（像合订本摊开，跨页图会在中缝切开）；页仍是一页一张图，不把一页排成两栏。翻页步进 2，
页号落在左边那一页。

**⑤ 门 + 真机**
headless 至少补四条：定版式起卷只画一张纸且正面采位图纹理 / 背面烘的是目标页 / 落定那一帧
不出现两张同一页 / 双页时中缝不切掉越过中缝的那半页。
真机走 `scrcpy-android`（不占手机主屏）：PDF 一本 + 漫画一本，看三件事 —— 页边黑带
（采样原点与捕获矩形不同源）、折页背面是不是下一页真字、双页中缝有没有少半页。
`adb input swipe` 判不了跟手，要录屏逐帧看（口径见 `doc/device-perf` 那条记忆里的配方）。

## 必须 / 可省

| 必须 | 可省 |
|---|---|
| ①②③同轮做完（闸 + 副本 + 采纹理） | 进场页位图也烘一张（定版式进场本来就在解码，收益小） |
| 有效性判据用「这一页所有格都在图集里」，不用「页号对上了」 | 定版式矢量页放大时的 `pinned_region` 重画进纹理（放大与翻页同时用是极少数） |
| `plan_sheets` 接管手之后必须在真机判跟手 | 双页背面（先只做单页 Curl，双页 Curl 可以第二轮再放） |
| 每一步单独过 `cargo test -p folio-app --lib`（659 条，~18 s） | 全量 `cargo test --workspace --lib` 留到推送前 |

## 落地账（2026-11-03）

- ① 捕获副本：`paint_fixed_paper` 多一条 `capture` 通道，只收页格位图；
  痕迹 / 选中留实时层；双页时两张页图一起进同一张纹理（`fixed_capture_images`
  是「里面真有图」的读数）。
- ② 闸：`body::render` 的「这一页每一格都已在图集里」替掉了 `!is_fixed()`；
  双页两页一起等。捕获副本这一帧没产出图时**不请求**，否则会把纸色记成已烘。
- ③ 平摊与卷曲：`plan_sheets` / `plan_flat` / `build_curl_mesh` 接管定版式；
  卷曲时旧页走纹理、只摆进场；单页背面是目标页整张，双页背面是目标跨页落在
  leaf 那一侧的那一页。跟手与松手时钟走 `swipe_geometry` 那条公共路。
- ④ 档与摆法：`fixed_turn_applies` / `fixed_turn_style` 删除；底栏那颗双页按钮
  与设置里「翻页动画」都不再筛。双页 = 相邻两页各占半张，步进 2，页号落在左页。
- ⑤ 门：`body::tests::fixed` 新增起卷 / 背面 / 跟手 / 平摊纹理 / 双页步进 /
  双页卷曲六条，旧的「定版式退到平移」改成「走折页」。
  **真机三件事（页边黑带 / 背面是不是真字 / 双页中缝）仍未看**，见文首 ⑤。
