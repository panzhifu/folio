# 样式适配进度记录

本文记录电子书作者 CSS 在 Folio 阅读引擎中的适配进度。它是进度记录，不是规范或实现承诺：当前状态以源码、`doc/渲染.md`、`doc/字体.md` 和 `crates/folio-format/src/css/computed/known.rs` 为准；历史测试记录不代替本次验证。

## 范围与判据

样式适配指把书籍作者 CSS 从解析、层叠、排版、绘制、命中/选区链路中兑现，或在不兑现时给出明确的降级口径。这里同时看两件事：

- **屏上生效**：声明改变了文字、块、背景、层叠或交互的结果；
- **统计口径**：`KNOWN_UNIMPLEMENTED` 中的属性表示「认得、接受但不生效」，不把常见出版写法计入 `ignored` 落差；移出该名单通常意味着它已真正生效、只收初值，或已有明确的降级出口，不能单凭移出就宣称完整浏览器等价。

CSS 输入限额、格式识别和文档接口见 `doc/format.md`；排版与绘制的现状入口见 `doc/渲染.md`；字体宽度档和逐字形绘制见 `doc/字体.md`。

## 当前进度（截至 2026-11-26）

### 已落地

- **字体宽度与绘制提示**：`font-stretch` 九档关键字/百分比进入 CSS 求值、继承、`FontKey` 度量键与绘制端选面；连续可变 `wdth` 轴仍降级。`-webkit-font-smoothing` 四档经逐字形接口落到绘制，不污染窗口级设置。
- **OpenType 特性**：`font-variant` 初值、`font-kerning`、`font-feature-settings`、`text-rendering` 折成塑造特性表，量宽与绘制共用。
- **条件块**：`@media` 宽度条件与 `@supports` 按声明支持度筛选兼容分支；判断不了的条件按成立处理，避免误藏兼容内容。
- **文本与块级布局**：`text-transform` / `small-caps` 只在字节长度和字符数都不变时换字；多栏一族（`columns`、`column-count/width/gap/fill/rule/span`）已接；Flex、Grid、表格与层叠序均有明确子集。
- **装饰与背景**：背景色、背景图、`background-clip` / `background-origin`、`border`、`box-shadow`、`text-shadow`、轮廓与毛玻璃单值 `blur()` 已进绘制链，定位盒管尺寸/相位、裁剪盒管边界。
- **竖排并格**：`-webkit-text-combine` / `text-combine-upright` 的当前实现在竖排里把 Unicode 数字按 `digits 2/3/4`（`all` 按两位）成组：整组按一格量宽，断点不落组内，后续位以零宽片段回退并沿交叉轴并排；不足一组的尾部留在原格。命中与选区按整组处理。字形保持直立，不做 CSS 旋转变体。

### 本轮新增/收口：多位与 Unicode 数字并格

当前工作区正在把早期「连续 ASCII 数字两两成组」扩展为多位 Unicode 数字分组；对应提交说明是「实现 text-combine 多位与 Unicode 数字并格」。主要改动：

- `crates/folio-render/src/combine_groups.rs` 统一分组规则：`all` 按两位，`digits n` 按声明位数夹到 2–4，字符边界成组，尾部不足一组保持不变；宽度折叠、禁断与命中共用同一份字节区间。
- 收集期按组修正断点，宽度表整组折到首字，后续字记零宽；断行只补完整组后的边界并摘掉组内断点。
- 绘制期按组生成片段：首片保留推进宽度，后续片回退并沿交叉轴并排；`cross_offset` 经 `WritingMode::project_delta` 同时供绘制与命中/选区。
- 核心命中/选区把原来的两位判断改为支持组内多片，点击任一位都给整组前后两个落点；选中任一位都整组高亮。
- 格式层补 `digits 3/4` 解析断言，排版层补全角数字、三位成组、四位成组与尾部不成组用例；`doc/渲染.md` 同步改写并格口径。

### 2026-11-28 补：@import 跟随与量具收口

- **`@import` 现在真的会跟**：清单样式进层叠前逐份展开（`css::expand_css_imports`，
  文本级、解析前），被引文件按自己的目录折 `url()`、递归展开内层 `@import`；环与
  深度封顶，远程与读不到的语句原样留下让解析器计 ignored。哈利·波特全集的
  `fonts.css`（`@import` 挂进来的）由此进入规则表，书内自定义字体能加载了；css-gap
  的「连规则都拼不出来」从 1 处降到 0 处。7 项单元测试覆盖 URL/字符串两形式、嵌套、
  环、深度、媒体条件、注释与词边界。
- **量具五书验证**：`css-gap` 跑齐本地五本真书（蛇结、Style Demo、哈利·波特全集、
  斗战狂潮校对版、合成书）合计约 120 万条胜出声明，**全部接住**：0 条「认得不生效」、
  0 条「不认识」。声明层的适配以现有语料论已经吃干净。
- **`@page` 的 `padding` 等无去处项可见化**：`RuleSet::parse` 现在给解析失败的
  页边距块打 note，css-gap 明细表能看见是哪几条（Style Demo 的 2 处就是
  `@page { padding: 0 }`）。它们仍是文档明确的降级，不是新缺口。
- **ruby 的 `justify` / `distribute` / `space-between` / `space-around` 与
  `inter-character` 维持不收**：五本真书语料里这些值 0 处，判不认识比猜一种摊法
  诚实，与 [`RubyAlign`] / [`RubyPosition`] 的既有口径一致。
- **内嵌音频的排版占位**：`<audio>` 在流式排版里占一条 48px 的块级行（排版只给
  几何与归属节点），播放器样子与播放属 app 层，见阅读器音频播放那条线。

### 2026-11-28 补：其他格式的样式普查与两个缺口

- **普查范围扩到非 EPUB**：`css-gap` 的打开路径是 `Document::open`，本就格式无关。
  跑齐 40 本（docx 9、odt 5、mobi/azw3 12、fb2 3、htmlz 1、mhtml 4、rtf 5、html 1、
  md 2、pdb 1、chm 3）。除两本（下述）外全部零落差：docx / odt / rtf / txt / fb2 的
  转换器产出的流本身不带作者声明，mobi / azw3 的清单 CSS 也全部接住。
- **状态伪类收认**（`selector::PseudoClass`）：`:link` 命中带 `href` 的 `<a>`，
  `:visited` / `:hover` / `:active` / `:focus` 解析收认但**永不命中**（静态阅读器
  没有运行时状态，声明进层叠不落元素，宁缺毋滥）。古登堡的 `pride.html` 里
  `a:link` / `a:visited` / `a:hover` 三族规则原先整块被丢（18 处拼不出来），现在
  链接配色真按作者的写法上屏；specificity 按 class 档计，`:link` 反序也盖住裸 `a`。
- **`-webkit-text-stroke` 收认不生效**：AZW3 语料（sample-obfuscated-fonts）176 个
  元素身上都有这条（Calibre 系的描边写法），gpui 没有文字描边通道，一期不生效；
  收认的意义在「不把整块样式计成不认识」，值再怪（样本书里就有
  `-webkit-text-stroke: -webkit-text`）也不丢。进 `KNOWN_UNIMPLEMENTED`。
- 两本书复跑：obfuscated-fonts 的 176 条「不认识」全数转成「认得不生效」，pride 的
  18 处拼不出块清零、声明总数 16220 → 16560。

### 明确边界与后续候选

- 连续可变 `wdth` 轴不做；`digits` 只收 2–4，`all` 沿用两位兼容口径；不做旋转变体。
- 布局子集边界：Flex 的 `-reverse`、`align-content`、`order`、baseline、`space-around` / `space-evenly` 不做；Grid 的 `grid-template-rows` 与嵌套 Grid 不做。
- `overflow` 只解析不裁切，滚动条与滚动交互不做；`position: sticky`、ruby 的 `inter-character` / `justify` 对齐仍属不认识或降级。
- `KNOWN_UNIMPLEMENTED` 决定 `ignored` 统计而非屏上效果；后续每兑现一族，应同时更新测试、现状文档和这份记录，避免名单移出与能力声明脱节。
