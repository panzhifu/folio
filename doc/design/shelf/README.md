# 书架设计稿（compact 档）

八屏。尺的逐条出处在 [`generate.py`](generate.py) 的文件头注释表里，共用的那份尺在
[`../_kit.py`](../_kit.py)。

| 文件 | 内容 |
| --- | --- |
| `01-shelf-grid` | 主架面：三列一排，组卡与书排在同一条流上 |
| `02-shelf-search` | 搜索有结果：词非空时查的是全库，进过组的也搜得出来 |
| `03-group-page` | 组那一页：顶栏是返回 + 组名 + 几本书，底栏整条收起 |
| `04-book-info` | 书信息：封面 + 两格可改的书名/作者 + 只有有值才摆的书目行 |
| `05-scan-sheet` | 扫描 sheet：0.85 档高的弹层，勾选清单加底部三颗钮 |
| `06-import-menu` | 三点导入浮层：三条动作，右缘对齐那颗三点钮 |
| `07-book-menu` | 书卡长按菜单：分组那一节把每一组摆成可勾的一行 |
| `08-shelf-grid-dark` | 主架面的深色对照 |

「还没有内容」那三屏（空书架、搜不到、组里空）在
[`../welcome/`](../welcome/README.md) —— 同一颗 `empty_state`，不在这儿画第二遍。

## 这一屏特有的几条

- **搜索框有词时右端多一枚清除钮**：`02-shelf-search` 里看得见，`01-shelf-grid` 里没有 ——
  这颗钮只在框里真有字时才在（`input.rs:531-535` 那句 `state.text(cx).len() > 0`），所以它
  同时也是「这一屏正在搜索」的标记。形状是 `clear_button()` 给的 `Button.xsmall()` 包一枚
  12 的 `Close`：钮盒 20 宽、右缘落在框内缩 10 那一格，词在钮左侧 6 的缝前截住。点它清空
  并把焦点留在框里，架面跟着回到满架那一片。
- **架面只有一把尺**：组卡与书卡同格同高（114.67 × 封面 172），谁最近被翻开谁的卡就在先，
  所以点开分组里的书时顶到第 1 格的是那张组卡。
- **没有进度条、没有已读标记**：书架那一格只报「是什么书」，读到哪儿是阅读页与书信息的事。
- **封面位是占位**：真机上有封面的书摆的是解码出来的那张图，稿子里一律画成 neutral-300
  压薄的占位灰。别把它读成界面颜色。没封面那一格才是实现本来的样子（格内书名、居中、次要色）。
- **组卡里那 2×2 是四张封面**，不是图标；不足四本时空槽吃 `muted` 底色，没有图标补位。

## 量到的一条不符

`shelf.empty_hint` 现译是「用右边的「导入」选一本 epub、markdown 或纯文本」，而 compact 那一条
顶栏上**没有叫「导入」的东西** —— 手机上是一根搜索框加一颗三点钮（`shelf/view/toolbar.rs:47-59`），
「导入」藏在点开的那条菜单里。那句话在桌面上成立，在手机上把读者往一个不存在的位置指。
稿子照现译画（`../welcome/04-empty-shelf`），因为改文案是另一笔账。
