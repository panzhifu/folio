# 统计设计稿（compact 档）

四屏。尺的逐条出处在 [`generate.py`](generate.py) 的文件头注释表里，共用的那份尺在
[`../_kit.py`](../_kit.py)。

| 文件 | 内容 |
| --- | --- |
| `01-stats-year` | 近 12 个月：热力图 + 图例 + 一句结论，横向要滚 |
| `02-stats-none` | 一年没读：满网格照画、全 0 档，只把结论换成那一句 |
| `03-stats-no-store` | 读不到书库：两行字，热力图整块不摆 |
| `04-stats-year-dark` | 近 12 个月的深色对照 |

## 这一屏特有的几条

- **整屏只有一张图**：主任务是「我的习惯长什么样」，那是**形状**而不是某个数，所以图占整屏，
  眉标、图例、结论各一行小字围着它，不并列第二块内容。
- **页面标题不写「统计」二字**：底栏那条导航已经把这一格点亮了，再写一遍是废话。眉标写的是
  **窗口**（「近 12 个月」），那才是导航没说的那半句。
- **图的下面永远跟一句结论**：这一屏连 tooltip 都没有，那一句是唯一的数通路（移动端浮层
  点不住这条是量过的）。不许只靠颜色传义 —— 深浅之外，读了多少天、累计多久、最长连续几天
  由那句话念出来。
- **两条「空」是不同的**：一年一天都没读时**图照画满**（53×7 全 0 档、月标签仍在），只把结论
  换成「还没有阅读记录」；读不到书库时整块图不摆，换两行字。前者是「没读」，后者是「查不到」。
- **分档是绝对档不是分位数**：`LEVEL_MINUTES = [15, 30, 60]`。分位数会让「每天都读半小时」
  那种极规律的习惯整年只亮一档，也会让今天与上个月不可比。
- **1..4 档是同一个图表色递进不透明度**，不是 `chart_1..chart_4`：那四个是分类色板，摆在一起
  读出来是四种东西，不是一件事的四个程度。

## 量到的一条：这一屏在手机上看不见今天

53 列 × pitch 11 = **580** 的内容宽，塞不进 384 − 24 − 28 = **332** 那一条可用宽
（`view/mod.rs:83-98` 实算）。实现选的是**不缩格子**（再小就看不出是一格一格的了），多出来的
部分横向滚（`view/mod.rs:249`）。于是初始那一帧停在最早那几周，**今天落在最后一列，不滚看不见**。

稿子画的就是滚到最左那一帧（右缘淡出说明还能往右滚）。要不要在进这一屏时把滚动位置摆到
最近那一周，是一个待决的问题 —— 它不是 bug，但「看我的习惯」这句话里，最近这几周是读者
最先要看的。
