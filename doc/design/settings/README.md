# 设置界面设计稿（compact 档）

设置界面（`crates/folio-app/src/ui/features/settings/`）手机那一档的 SVG
设计稿。十一个屏的几何常量、主题 token、图标表与行构造器都取自
[`../_kit.py`](../_kit.py) —— 那是各屏共用的那份尺，本目录的
[`generate.py`](generate.py) 只写「设置这一屏摆哪几行」。
**SVG 是真相源，不要手改 SVG**：改版式先改 `_kit.py` 顶部的常量（或本文件的屏定义），
再重出。每张 SVG 旁边摆着一张同名的真机分辨率 PNG（1080×2400），直接点开就能看。

| 文件 | 内容 |
| --- | --- |
| `01-root-light` | 根屏（「我的」）：入口列表一行一页，底栏在场 |
| `02-appearance` | 外观：浅深与两侧主题、主题目录 |
| `03-typography` | 文字：字号 / 行距 / 段距 / 缩进 / 对齐 / 翻页 / 划线 |
| `04-layout` | 版面：最大行长、左右页边距 |
| `05-fonts` | 字体：正文字体家族 |
| `06-library` | 书库：位置、文件夹监听、Wi-Fi 传书 |
| `07-toc` | 目录：密度、标题行数、已读浅色 |
| `08-storage` | 存储：占用环图、清理、数据目录 |
| `09-about` | 关于：版本、更新与反馈、界面语言 |
| `10-pick` | 选项屏：推一屏勾选，勾是唯一的右端标记 |
| `11-typography-dark` | 「文字」子页的深色对照 |

## 重出

```bash
python3 generate.py    # 一条命令重出 11 张 SVG + 11 张真机分辨率 PNG
```

PNG 渲染走 `rsvg-convert`（librsvg），机器上没有它时脚本只出 SVG 并提示。
画布 384×853 是魅族 20（1080×2400 @ 450dpi）的逻辑分辨率；其它设备按同一
逻辑网格缩放。

## 版式约定（2026-10-24 定稿）

- **行内不摆灰色说明文字**：每行只有标题与控件，44 一行。取值范围、开关的
  后果这些话从行上撤掉 —— 代价是「最大行长 0 表示随窗口铺满」这类约定没了
  界面内的解释，靠各控件自己的语义兜住。
- **卡片上方不摆节头**：组与组只靠 32 的缝分开，整页是一串光卡。这条从前只有存储那一页
  做到（`Page::no_group_titles`），现在推广到了全部页：`compact.rs` 里那条渲染路径已经
  没有了，规格里那个字段跟着删干净 —— 桌面的组标题同时是侧栏子项，那边不许去。
- 服务状态字（Wi-Fi 传书没开时的那句、检查更新的「还没查过」）是**行的内容**而不是注释，
  保留灰色。

## 数字与颜色的来源

初稿没有自造样式，每一格都取自实现与依赖的真值：

- **几何**对齐 `settings/view/compact.rs`：行命中高 44、图标槽 28、组缝 32、
  卡圆角 8（`radius_lg`）、顶栏带高 44、底栏 56、Switch 44×24、分隔线缩进
  16/56；
- **颜色**是 gpui-kit `Default Light` / `Default Dark` 的 token 值
  （shadcn neutral 系；存储环用 chart.1–5），深浅两侧各出了一张对照；
- **文案**取 `crates/folio-core/locales/zh-CN.toml` 的现译；
- **取值**取 `folio-core` 配置默认值（字号 17、行距 1.75、字体 LXGW WenKai、
  版本号取自 workspace）；
- **图标**抄 `gpui-kit-assets` 里 Lucide 的原 path（24 网格、stroke 2）。
