# 界面设计稿（compact 档）

按屏分的 SVG 设计稿，覆盖手机那一档。**SVG 是真相源，不要手改 SVG** —— 改版式先改
生成器，再重出。

| 目录 | 内容 | 屏数 |
| --- | --- | --- |
| [`settings/`](settings/README.md) | 设置：根屏、八页、选项屏、深浅对照 | 11 |
| [`shelf/`](shelf/README.md) | 书架：架面、搜索、组、书信息、扫描、两套菜单、深色对照 | 8 |
| [`reader/`](reader/README.md) | 阅读页：正文、浮层、设置面板、目录、划选、笔记、图片、分享卡 | 9 |
| [`stats/`](stats/README.md) | 统计：热力图有数据 / 一年没读 / 读不到书库 / 深色对照 | 4 |
| [`welcome/`](welcome/README.md) | 首次启动，与「还没有内容」那四屏 | 6 |

## 共用的那一份尺

[`_kit.py`](_kit.py) 装着各屏共用的一切：画布与几何常量、`Default Light` / `Default Dark`
两份 token、Lucide 图标表、遮罩与弹层与按钮与输入框与封面格这些屏级构件、行构造器、卡片装配。
每条 `generate.py` 只写自己那几屏摆哪几行。

**一个数不许在两份文件里各写一遍。** 行高从 44 改成 48，改 `_kit.py` 一处，38 张图跟着动；
分文件复制常量迟早分叉，而分叉在设计稿里是静默的错 —— 两张图差 4 没人看得出来哪张是对的。

## 重出

```bash
python3 _kit.py            # 什么都不做，只确认这份能 import
for d in settings shelf reader stats welcome; do (cd $d && python3 generate.py); done
```

PNG 渲染走 `rsvg-convert`（librsvg），机器上没有它时只出 SVG 并提示。每张 SVG 旁边摆着一张
同名的真机分辨率 PNG（1080×2400），直接点开就能看。

## 数字与颜色的来源

初稿没有自造样式，每一格都取自实现与依赖的真值：

- **几何**对齐 `crates/folio-app/src/ui/`，逐条带 `文件:行号` 写在各自 `generate.py` 的文件头
  注释表里 —— 那张表是这些稿子最值钱的部分，改版式时先回去核一遍它还对不对；
- **颜色**是 gpui-kit `Default Light` / `Default Dark` 的 token 值（shadcn neutral 系），
  深浅两侧各出了一张对照；
- **文案**取 `crates/folio-core/locales/zh-CN.toml` 的现译，一字不重写；
- **取值**取 `folio-core` 配置默认值（字号 17、行距 1.75、页边距 24、字体 LXGW WenKai、
  版本号取自 workspace）；
- **图标**抄 `gpui-kit-assets` 里 Lucide 的原 path（24 网格、stroke 2）。

画布 384×853 是魅族 20（1080×2400 @ 450dpi）的逻辑分辨率；其它设备按同一逻辑网格缩放。
桌面那一档**没有出稿**：那边直接用 gpui-kit 的组件，自造稿子容易和组件的真实长相分叉。

## 版式约定（2026-10-24 定稿）

- **行内不摆灰色说明文字**：每行只有标题与控件，44 一行。取值范围、开关的后果这些话从行上
  撤掉 —— 代价是「最大行长 0 表示随窗口铺满」这类约定没了界面内的解释，靠各控件自己的语义
  兜住。桌面那头保留说明（那边有宽度，且 `spec::Row::desc` 只有桌面读）。
- **卡片上方不摆节头**：组与组只靠 32 的缝分开，整页是一串光卡。桌面的组标题同时是侧栏子项，
  那边不许去。
- 服务状态字（Wi-Fi 传书没开时的那句、检查更新的「还没查过」）是**行的内容**而不是注释，
  保留灰色。

## 出稿过程中量出来的不符

画每一屏时对着实现核数，撞上来的几条记在这儿 —— 它们是待办的账，不是画图的错：

1. `shelf.empty_hint` 现译「用右边的「导入」选一本 epub、markdown 或纯文本」，而 compact 的
   顶栏上只有搜索框加一颗三点钮，「导入」藏在菜单里。那句话在桌面成立，在手机把读者往一个
   不存在的位置指。（`shelf/README.md`）
2. 浅侧弹层遮罩只有 5% 黑（`theme().overlay` = `#0000000d` × `scrim_alpha`），弹层与底噪几乎
   不分。深色侧是 20%，两侧观感差一个量级。（`_kit.py` 的 `scrim`）
3. 统计那一屏在手机上**必须横向滚**：53 列 × pitch 11 = 580 的内容宽塞不进 332 的可用宽，
   而格子不缩到 `CELL_MIN` 以下。初始停在最早那几周，今天落在最后一列不滚看不见。
   （`stats/README.md`）
