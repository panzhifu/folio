九屏。尺的逐条出处在 [`generate.py`](generate.py) 的文件头注释表里，共用的那份尺在
[`../_kit.py`](../_kit.py)。

| 文件 | 内容 |
| --- | --- |
| `01-reading-clean` | 干净态正文页：上下各一条 28 的带，中间是版心 336 的正文 |
| `02-reading-chrome` | 浮层态：顶栏 44（返回 + 书名 + 章名），底栏一张只圆上两角的卡 |
| `03-reading-panel` | 浮层 + 阅读设置面板：字号与亮度两条滑条、翻页动画向上开的浮层 |

## 这一屏特有的几条

- **阅读层是整屏的**：没有应用底栏。切出/切入那两条带的判据在 `chrome.rs:203-228` ——
  横向按 1/3 分三区：左边上一页、右边下一页、中间切出或切入浮层，RTL 只把左右对调；
  `chrome.open` 时任何一区都只 dismiss（`dismiss` 先收面板再收整层）。
- **正文的度量是量出来的**：字号 17 × 行距 1.75 = 行盒 29.75，版心 384 − 2×24 = 336，
  一行 19 个中日文字，首行缩进 34（`indent_em` 2.0），段距 12.75（相邻段取 max 合并）。
  稿子里的两端对齐是用 SVG 的 `textLength` 落实的。
- **稿子的字形与真机不同**：真机排的是配置里那个字体家族（默认 `LXGW WenKai`，一款楷体），
  稿子统一用 Noto Sans CJK SC。**度量按 17 / 29.75 走，所以行位置是对的**，字形不是。
- **高亮压在字下面**，不是覆盖层（可重排正文里它是底色带，`body.rs:2530` 那一个 0.35）。
- **划选浮条不是模态**：没有遮罩，正文照常在那儿，浮条只是锚在选区上方、放不下翻面。
- **目录在手机上是从底部弹起的弹层**（0.85 / 0.5 两档），左抽屉那一档是宽屏才有的。
  当前章的标记是「整行 `muted` 底色 + 距左 2.1 那一根 2.9 宽的条 + 半粗」，已读只降成次要色。
- **分享卡不进屏幕**：它是离屏渲成 PNG 再交给系统分享面板的（`platform/mod.rs:370` 那格
  `RENDERS_SHARE_CARDS`），所以第八屏画的是那张产物本身，按 336×504 等比缩下来看版式。
- **五档标注色**取主题的 `red / magenta / cyan / green / yellow`（`annotations.rs:652-658`），
  顺序对上 `ANNOTATION_COLORS` 的 `ruby / rose / sky / lime / amber`；稿子里写的是那五档在
  shadcn 调色板上的 500 阶，默认那一种（`amber`）不变。
