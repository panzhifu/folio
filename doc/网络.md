# 网络 API 设计

出网与入网的一条口。核心是 `Transport` 抽象：协议与实现分开，全部离线可测。

## 使用顺序（一屏看完）

```rust
// 1. 一个 Transport 就是「能发请求」；生产给 ureq 那份，测试给假传输
let transport = ...;
// 2. 协议层收 Transport：更新检查、OPDS、翻译、AI 全是同一个形状
let outcome = update::check(&transport, "0.1.4")?;
let feed = opds::parse(&body, &base, &content_type)?;
// 3. 网盘抽象成 RemoteStore：列、读、写、下载
let entries = drive.list("books")?;
```

## API 一览

### Transport — 唯一出网原语（folio-net）

传输抽象与 WebDAV 已独立成 folio-net crate；`folio_core::net::remote::*` 旧路径经
模块别名沿用，消费方一行不改。

```rust
pub trait Transport: Send + Sync + 'static {
    fn send(&self, req: Request) -> Result<Response, Error>;
}
Request::new(method, url).header(k, v).body(bytes)
Response { status, body }.header(name)
```

- `Method`：GET / PUT / PROPFIND…（WebDAV 的动词也在）。
- `redacted_url()`——日志里的地址打过码，密钥不进日志。

### RemoteStore / Drive — 网盘（net::cloud）

```rust
pub trait RemoteStore: Send + Sync + 'static {
    fn list(&self, path: &str) -> Result<Vec<Entry>>;    // 列一层
    fn get(&self, path: &str) -> Result<Vec<u8>>;        // 读小对象（快照）
    fn put(&self, path: &str, body: Vec<u8>) -> Result<()>;
    fn mkdir(&self, path: &str) -> Result<()>;
    fn download(&self, path: &str, sink: &mut dyn Sink, cancel: &Cancel) -> Result<u64>;
}
pub trait Drive: RemoteStore { fn label(&self) -> &'static str; }
```

- 三份实现：WebDAV、百度、阿里；`CloudProvider` 管授权。
- 给导入来源（`CloudSource`）与浏览界面共用；整本书走流式 `download`。

### OPDS（net::opds）

```rust
fetch(...)                                       // 取 feed
parse(body, base, content_type) -> Result<Feed, Error>
Feed { entries: Entry { title, acquisitions, … } }
auth_header(user, pass) -> Option<(String, String)>
```

- 相对链接按 feed 地址解析。

### Wi-Fi 传书（net::transfer）

```rust
TransferServer::start(config, on_file) -> Result<TransferServer>
server.addr() / server.pin() / server.urls() / server.stop()
```

- 设备起 HTTP 服务，局域网浏览器上传；`pin()` 是配对码；
  `on_file` 把落盘的文件递给导入。**tokio 只许住在这里**。

### 局域网同步（net::lansync）

- 握手：`Hello` / `HelloReply` / `Auth`——证明持有密钥，不是声称 id。
- 对账：`Manifest`、`missing(local_hashes, &remote)` 算对方缺哪几本、`Report` 记结果。
- 自己不起服务器（挂 transfer）、不拨连接（走 Transport）。

### 更新检查（net::update）

```rust
check(&transport, local_version) -> Result<Outcome, Error>
asset_for_platform(&release) -> Option<&Asset>    // 挑这一端的包
parse_checksums(text) -> HashMap<String, String>  // 验 sha256 才认
```

### 会员兑换（net::redeem）

一个爱发电订单号换会员天数；只校形状 + 一次 POST，判单在服务端。

翻译与 AI 也住在 net 下、形状同源，各有一篇：见 翻译.md / AI.md。

## 优化（现有实现里已经做了的）

- **协议与实现分开**——Transport 是 trait，每个协议都能拿假传输 + fixture 测。
- **不新起 HTTP 栈**——出网客户端是 gpui 依赖树里已在编译的 reqwest 补的一格。
- **tokio 关在家里**——只许传书用，公共签名不漏 Future，其余全是同步形状。
- **同步 API 对上管线形状**——「一个请求流到底」，没有回调地狱。
- **密钥不进日志**——地址打码；口令、正文都不落日志。
