# 听书

`folio-speech` 负责后端生命周期、声音目录和逐句合成；`folio-core::speech` 保留重导出。应用的 `services::speech` 持有共享状态与选择确认，阅读会话负责句子、字符坐标、跟读和位置。

## 准备与生命周期

会员资格与平台/JNI 就绪后，外壳在首帧之后启动无声准备。初始化在线程中执行，只构造后端、安装回调与读取目录，不读取书文、不合成、不申请音频焦点，也不弹朗读通知。打开听书页只定位当前句，播放须由用户触发。

进程只保留一条在途初始化。通用层十秒超时后标记失败；后台构造返回前仍保留槽位，不能叠加新绑定。Android 桥自身六秒超时并关闭实例，早到的 onInit 延后至构造完成，晚到回调不复活旧会话。显式重试才重新准备；退出时停止并释放后端。系统服务构造本身阻塞时，通用线程不能强行取消外部函数，后端返回后清理。

## 接口与状态

- `engine()` / `prewarm()`：返回进程句柄；应用通过共享服务取得，避免重试后页面持有不同代的句柄。
- `snapshot()`：持久状态、目录、默认/已应用音色、修订和错误。`ready()` 为兼容可用性查询。
- `select_voice(preferred, language)`：独立确认通道，成功后设置页才保存；不消费播放事件。
- `SpeakWithVoice { text, voice, language, rate, pitch }`：停止旧句、校验/设置参数和声音、开始新句；任一步失败不会继续播放。
- `events()`：竞争通道，只由当前阅读会话消费，返回 `Delivery { generation, event }`。界面实际更新前校验引擎实例和 `accepts()`，已排队的旧通知也不能影响新句。`Done` 才推进；`Failed`、系统取消、手动 `VoiceChanged` 都停在当前句。
- `Backend`：在专职线程构造和使用，无 GPUI 依赖。每句携带独立 ID，停止和换句后的旧回调被丢弃。

旧 `Speak`、`Stop`、`SetRate`、`SetPitch` 仍可用。新阅读路径使用原子请求。语速/音高的语义倍率范围为 0.5–2.0，平台转换由各后端负责。

## 音色与角色

音色 key 保存后端、引擎作用域和原始 ID，语言保存完整 BCP-47 标签；不保存列表序号或仅用显示名。目录保留联网要求、安装状态的未知值。只允许已确认安装的本地音色，不自动下载或尝试每个声音。

首选声音失效时，按完整语言、主语言、安全默认回退；没有安全候选则暂停并解释。配置保留失效偏好，设置页提示，不永久改成临时回退值。语速估计在实际音色变化后清零。

配置追加 `narrator_voice`、`language`、`roles`，旧三字段配置继续读取。角色有稳定 ID、名称、段首前缀和可选音色：例如前缀“张三：”使该段内所有句子使用张三的音色。空音色继承旁白；角色音色失效也回到旁白。未匹配段落使用旁白，不推断说话人，不剥离原文前缀，因此高亮、批注与阅读坐标不变。角色列表最多 32 条，设置页阻止空规则和重复前缀。

设置页的旁白和角色变更在后端确认后才写配置；播放中变更停止当前句，不自动恢复。再次播放时从该句开头继续。音色偏好属于本机配置，不新增跨设备音色同步。

## 平台边界

| 平台 | 后端 | 身份与能力 |
| --- | --- | --- |
| Linux | speech-dispatcher 0.16.0 | 使用 `configured:<module>` + voice name，不宣称已证明实际绑定模块。仅所有可用回退模块均为已知本地模块时允许离线选择。系统默认音色不可查询，自动档需语言候选；构建需 libclang/libspeechd 开发文件，运行需 speechd |
| Android | 自有 FolioSpeech + 系统 TextToSpeech | 公共 API 无法证明实际绑定包；用 `requested:<包名>` 请求作用域，并验证当前目录 ID。完整语言及安装事实来自系统声音目录 |
| Windows/macOS/iOS/HarmonyOS | 尚无后端 | 反馈不可用，不将编译通过称为能够发声 |

Android 不再依赖 tts crate 的 `rs.tts.Bridge`。Manifest 保留 TTS 服务查询声明，R8 保留 FolioSpeech；Gradle 对旧构建目录 libtts 副本的排除继续有效。

## 阅读行为与验收

按标点切句，长句按停顿拆分；一句一个请求。`auto_scroll` 开启时，跨段或当前句不可见才跟读。手动翻页不改变正在朗读的句子顺序；暂停后可从文稿重选。跨章等待排版最多五秒。退出阅读页保存当前句起点，与普通阅读共用位置记录。

假后端测试覆盖静默单实例准备、超时/重试、声音确认、参数错误、卸载与旧句回调隔离；配置测试覆盖旧数据与完整语音身份往返。GPUI 测试覆盖设置交互和当前句保留。实际命令与结果登记在听书专项计划；桌面/Android 编译与真实音频、冷/热延迟分开验收。未经用户点名不操作手机。
