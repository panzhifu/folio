# 渲染 API 设计

把「内容」变成「屏幕上的像素」，分两段：排版（folio-core，零 GPUI）与绘制（folio-app）。

## 管线（一屏看完）

```
Dom + StyledDom（format 解析 + CSS 求值）
  → 排版三步：collect → wrap → children ⇒ BlockBox / LineBox 扁平两张表
  → 分片：Fragmentainer 按可视高度切出 Fragment（多栏用 column_width）
  → 绘制：Scene::build 把行盒、图片、块背景摆进一帧（GlyphRun 逐字形）
  → 图集：图片异步解码进 ImageAtlas，按 key 取帧画
```

## API 一览

### 排版（folio-render，零 GPUI）

排版引擎已独立成 folio-render crate；`folio_core::layout::*` 旧路径经模块别名沿用，
消费方一行不改。

- **排版三步**——`collect`（行内子树展平成文本 + piece 表，每段带自己的样式）
  → `wrap_lines`（断行，UAX #14，中文禁则）→ `children`（块级摆放、外边距折叠、
  `text-indent`、`text-align`）。
- **输出**——`BlockBox` / `LineBox` 扁平两张表；坐标是布局空间的绝对值，绘制直接取用。
- **分片**——`Fragmentainer::new(&layout, &styles, options)`；`Fragment` 是一页（栏）
  里那一段行盒；`column_width(total, columns, gap)` 算栏宽。
- **缓存**——`BlockCache` 块级缓存，失效键在 `key`：没变的块不重排。键对读者偏好
  只要求 `Serialize`（core 把整份 `config::Reader` 递进来，字段表钉子在 core 的
  `tests/layout_key_contract.rs`）。
- **字体**——`FontKey::of(style)` 字体候选表；`StyleArena::intern(RunStyle)` 样式去重；
  `cjk_latin_gap` 中西文间距。

### 绘制（folio-app reader view）

- **GlyphRun**——一行字形的构建器，链式拼：
  `GlyphRun::new(text, font, size).spacing(...).in_box(h).at(x, baseline)
  .on_flow(mode).color(c).decorate(u, lt).shadowed(s).keyed(k)`。
- **Scene**——一帧的全部：`Scene::build(...)` 收块背景（`BlockDecor`）、可见图片
  （`VisibleImage`）、字形 run。
- **ImageAtlas（图集）**——`prepare(request)` 后台解码、`ready(key)` / `failed(key)`
  查状态、`painted(...)` 取帧、`trim_for_memory_pressure()` 内存压力收缩。
- **定版式**——`Document::render_page(page, edge)` 栅格化整页 PNG、
  `render_page_region(...)` 按放大档重画看得见的那一块。

### 仿真翻页

- 页面网格与 uniform 的纯 CPU 定义在 `folio-curl`（独立 workspace 成员）；
  Mesh primitive 与片元圆柱受光在 patch 过的渲染器里。

## 优化（现有实现里已经做了的）

- **扁平表不建树**——分页要按高度切行盒，树形碍事；父子关系按行盒包含关系还原。
- **断行引擎自持**——不调框架的折行器（一次只能按一种字体折一行），
  禁则与基线自己说了算。
- **样式去重**——StyleArena 把重复的 RunStyle intern 成引用，一张表不存第二份。
- **块级缓存 + 失效键**——窗口尺寸、样式没变的块不重排。
- **图片异步解码**——prepare / ready 两态，解码不卡帧；缺图空着不报错。
- **逐字形绘制两端共用**——桌面与移动同一份，平台间只剩导航栏占宽占高的数据差别。
- **水墨档**——主题色统一去饱和压半灰，图集负责压像素。
- **内存压力逐档收缩**——图集按预算 trim，不是一律清空。
