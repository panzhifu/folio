# 渲染 API 设计

把「内容」变成「屏幕上的像素」，分两段：排版（folio-core，零 GPUI）与绘制（folio-app）。

## 管线（一屏看完）

```
Dom + StyledDom（format 解析 + CSS 求值）
  → 排版三步：collect → wrap → children ⇒ BlockBox / LineBox 扁平两张表
  → 分片：Fragmentainer 按可视高度切出 Fragment（多栏用 column_width）
  → 绘制：Scene::build 把行盒、图片、块背景摆进一帧（GlyphRun 逐字形）
  → 图集：图片异步解码进 ImageAtlas，按 key 取帧画
```

## API 一览

### 排版（folio-render，零 GPUI）

排版引擎已独立成 folio-render crate；`folio_core::layout::*` 旧路径经模块别名沿用，
消费方一行不改。

- **排版三步**——`collect`（行内子树展平成文本 + piece 表，每段带自己的样式）
  → `wrap_lines`（断行，UAX #14，中文禁则）→ `children`（块级摆放、外边距折叠、
  `text-indent`、`text-align`）。
- **Flex 容器**——`display: flex` / `inline-flex` 走第三套布局 `flex.rs`：主轴
  `flex-direction`（row / row-reverse / column / column-reverse）、`flex-wrap` 分行、
  `flex-basis` / `flex-grow` / `flex-shrink` 的尺寸分配、`align-items` / `align-self`
  （含 baseline）、`align-content`（多行交叉轴）、`justify-content`（含 space-around /
  space-evenly）、`order`（只改视觉序，不改源序）、`gap`（分 row/column 两分量）。
  纯尺寸数学在 `flex.rs`（可独立测），盒子摆放与平移在 `collect::Ctx::flex`。全程在
  **逻辑坐标**里排，竖排由 `Layout::assemble` 统一转置，所以横排竖排共用一套；
  `light` 档复用同一逻辑只量高，章高与完整档一致。
  子集边界：Grid 已接列/行轨道、自动放置与块级嵌套；`align-content` 只在多行容器上
  生效，单行容器不受它影响。
- **层叠序**——`stacking.rs` 给每行存根到 owner 的完整 z 链（定位元素 z-index≠0、
  `opacity<1`、`transform≠none` 都建立层叠上下文），绘制侧按 `(z 链字典序, 源序)` 稳定
  排序再画；嵌套层的相互覆盖因此不只看最近一层。正文源序、命中、分页都不动；
  `line_z` 全 0 时零回归。`opacity` 按 run 乘字色 alpha（子级乘祖先乘积）；
  `transform` 的 `translate` 只挪墨迹、`scale` 只建立层叠上下文，不改断行与命中。
  `overflow: hidden|clip` 会在排版收尾时折成逐行的裁剪框：绘制侧按框裁字形、插图与块装饰，
  `scroll` / `auto` 仍按可见处理（没有滚动容器）；命中点在框外不命中，选区只丢整行出框的矩形，
  源字符锚点不动。逐字形/逐像素的矩形裁剪走 GPUI 的矩形 content mask，圆角与折页那种非矩形
  形状不在这一档里。
- **输出**——`BlockBox` / `LineBox` 扁平两张表；坐标是布局空间的绝对值，绘制直接取用。
  `Layout::line_z` 与 `lines` 等长，只供绘制排序，不进命中/分片。
- **分片**——`Fragmentainer::new(&layout, &styles, options)`；`Fragment` 是一页（栏）
  里那一段行盒；`column_width(total, columns, gap)` 算栏宽。
- **缓存**——`BlockCache` 块级缓存，失效键在 `key`：没变的块不重排。键对读者偏好
  只要求 `Serialize`（core 把整份 `config::Reader` 递进来，字段表钉子在 core 的
  `tests/layout_key_contract.rs`）。
- **字体**——`FontKey::of(style)` 字体候选表（含 `font-stretch` 九档），量宽与绘制共用
  同一个 `gpui_font`，绘制端按档换面；`StyleArena::intern(RunStyle)` 样式去重；
  `cjk_latin_gap` 中西文间距。连续 `wdth` 轴不做。`-webkit-font-smoothing` 四档经
  `RunStyle` 到逐字形 `paint_glyph_with_mode`，不污染窗口级渲染设置。
- **竖排并格**——`-webkit-text-combine` / `text-combine-upright` 在竖排里把 Unicode
  数字按 `digits 2/3/4`（`all` 按两位）成组：整组按一格量宽、断点不落在组中间，后续位
  以零宽片段回退并沿交叉轴并排；不足一组的尾部留在原格。`LineRun::cross_offset` 经
  `WritingMode::project_delta` 同时供绘制和命中/选区（整组落点、整组高亮）。字形保持
  直立，不做 CSS 的旋转变体。

### 绘制（folio-app reader view）

- **GlyphRun**——一行字形的构建器，链式拼：
  `GlyphRun::new(text, font, size).spacing(...).in_box(h).at(x, baseline)
  .on_flow(mode).color(c).decorate(u, lt).shadowed(s).keyed(k)`。
- **Scene**——一帧的全部：`Scene::build(...)` 收块背景（`BlockDecor`）、可见图片
  （`VisibleImage`）、字形 run。
- **ImageAtlas（图集）**——`prepare(request)` 后台解码、`ready(key)` / `failed(key)`
  查状态、`painted(...)` 取帧、`trim_for_memory_pressure()` 内存压力收缩。
- **定版式**——`Document::render_page(page, edge)` 栅格化整页 PNG、
  `render_page_region(...)` 按放大档重画看得见的那一块。

### 仿真翻页

- 页面网格与 uniform 的纯 CPU 定义在 `folio-curl`（独立 workspace 成员）；
  Mesh primitive 与片元圆柱受光在 patch 过的渲染器里。
- 当前固定的 fork 在 wgpu、DirectX 和 Metal 都绘制 `PageCurlMeshes`；应用的 Curl 档统一走卷页几何，不再按 Windows/Apple 静态降级为滑动。无头回归验证手势、双页 leaf 尺寸、正背面捕获与页面位移；真实 GPU 画质仍需各平台窗口验证。

## 优化（现有实现里已经做了的）

- **扁平表不建树**——分页要按高度切行盒，树形碍事；父子关系按行盒包含关系还原。
- **断行引擎自持**——不调框架的折行器（一次只能按一种字体折一行），
  禁则与基线自己说了算。
- **样式去重**——StyleArena 把重复的 RunStyle intern 成引用，一张表不存第二份。
- **块级缓存 + 失效键**——窗口尺寸、样式没变的块不重排。
- **图片异步解码**——prepare / ready 两态，解码不卡帧；缺图空着不报错。
- **逐字形绘制两端共用**——桌面与移动同一份，平台间只剩导航栏占宽占高的数据差别。
- **水墨档**——主题色统一去饱和压半灰，图集负责压像素。
- **内存压力逐档收缩**——图集按预算 trim，不是一律清空。

阅读会话的缓存盘点和回收由 `reader/model/memory.rs` 负责：图集保留当前屏与仍被借用的图片，布局保留 DOM、行盒、页表与字符坐标，只释放可重建的块、shaping 和行片段缓存。压力后暂停预取 5 秒，预算检查在冷却期内不反复清理当前页刚重建的缓存。缓存日志区分实测/估算/未知，并报告会话采样峰值；它不证明所有进程内存都受预算约束。

阅读会话持有 `(revision,index_generation)` 的索引快照与租约，通过固定版本文档入口取正文。后台来源更新只发布Ready候选；显式切换先保存旧坐标代进度、停止旧朗读并释放本会话租约，有其它阅读窗口时保留旧版本并提示。成功切换重建Document/Book、清图集、字形、选择与弹层，捕获提交单元也换新，旧绘制回调无法提交到新版。目录搜索及跳转、删除回调以书号和坐标代共同校验；删除与撤销再核对记录所属书目，防止两本书版本号相同的旧帧误操作。笔记导航按稳定记录ID查本版本已验证的位置投影，找不到时保留原文并提示，不拿旧章号跳转。
