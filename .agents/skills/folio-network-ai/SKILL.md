遵循 [AGENTS.md](../../../AGENTS.md) 与 [工程规范](../../../doc/工程规范.md)，按范围读 [网络](../../../doc/网络.md)、[AI](../../../doc/AI.md)、[翻译](../../../doc/翻译.md) 与当前协议实现。机制只接参数，配置挑选留在 core 入口。

检查 `RequestLimits` 是否在真实传输路径生效，分别处理连接、空闲读取、总预算与实际响应大小。SSE 要验证跨块拼接、单事件/累计上限、完成标记与中断；失败必须 abort 落地 sink，不能把半成品当成功。取消请求与资源已退出分别取证；付费 POST 不因断线自动重发。

使用 Mock Transport 或本地假服务器制造超限、静默断流、失败重试及取消，断言最终结果和文件状态。地址、错误、Debug、日志和反馈只保留安全元数据；哨兵凭据验证不能改变配置或备份序列化。检索实际测试名后定向执行，不读真实用户密钥、不发付费请求，不为问答引入 Agent Runtime。
